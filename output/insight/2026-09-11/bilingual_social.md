# Agent 的瓶颈不是智商，是身份证

今天最值得记一笔的，不是 OpenAI 又发了什么新 API，而是同一批 Agent 在现实世界里被 CAPTCHA 拦住了。

Anthropic 的研究显示，自主 Agent 对 CAPTCHA 的厌恶程度和你我一样——它们过不去。与此同时，公共服务正在被 Agent 请求淹没。这两件事放在一起，指向一个被严重低估的事实：Agent 的瓶颈已经不在智能水平，而在它没有身份、没有准入凭证、没有为它设计过的承载系统。

对比一下供给侧的速度。OpenAI 一天之内甩出 Agents API 和 Data Agent，把 Agent 变成可托管、可编排、可长时运行的生产级基础设施，还顺手嵌进企业数据分析场景。平台层已经准备好了。但现实世界这边，一个「证明你是人」的小方块就能让 Agent 原地卡死。

更有意思的是 Meta 的 Muse 冲上美国 App 榜第二。数据上这是消费级 Agent 第一次真正跨过主流门槛，但上手体验被 The Verge 直接评价为「有效但令人毛骨悚然」。采用率和信任度在背离——越深入你的个人上下文，效率越高，心理成本越难消化。

这三件事其实是同一件事：供给侧的标准化速度，已经明显快于社会侧接纳与治理的速度。Agent 能帮你拿到本该属于你的福利，也能把公共系统冲垮；能成为你的日常入口，也能让你后背发凉。同一个行为，同时是赋权和失序。

所以别再问「下一个模型什么时候更强」。该问的是：谁给 Agent 发身份证？谁来定它的准入规则？谁为它造成的洪流负责？

这些问题不解决，Agent 就永远停在演示阶段——不是因为它不够聪明，而是因为世界还没给它开门。

# The Bottleneck for Agents Isn't IQ — It's ID

The most important thing today isn't another OpenAI API drop. It's that the same class of agents got stopped cold by a CAPTCHA.

Anthropic's research shows autonomous agents hate CAPTCHAs just like you do — they can't get through. Meanwhile, public services are getting flooded with agent requests. Put those two together and you get the story nobody's telling: the bottleneck for agents isn't intelligence anymore. It's that they have no identity, no admission credentials, and no infrastructure built to carry them.

Look at the supply side. OpenAI shipped the Agents API and a Data Agent in a single day — turning agents into production-grade infrastructure that's hostable, orchestratable, and long-running, then embedding it straight into enterprise data workflows. The platform layer is ready. The real world, meanwhile, gets bricked by a "prove you're human" checkbox.

Then there's Meta's Muse hitting No. 2 on the US App Store. By the numbers, it's the first consumer agent to genuinely cross into mainstream. By the hands-on review, it's "effective and creepy" — The Verge's words. Adoption and trust are diverging. The deeper it goes into your personal context, the more efficient it gets, and the harder the psychological cost is to swallow.

These are all the same story: the supply side is standardizing faster than society can absorb and govern it. An agent can help you claim benefits you're owed and also overwhelm the public systems that provide them. It can be your daily entry point and also make your skin crawl. The same behavior reads as empowerment and as disorder.

So stop asking when the next model gets smarter. Ask who issues agents an ID. Who sets their admission rules. Who owns the flood they create.

Until those questions get answered, agents stay in demo mode — not because they're not smart enough, but because the world hasn't opened the door.
