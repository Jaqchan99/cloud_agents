# Agent 的战争已经不在模型层了

Agent 的战争已经不在模型层了。

今天两条新闻放在一起看很有意思：Google 把 Gemini 和搜索开放给第三方应用（https://techcrunch.com/2026/10/28/as-ai-agents-reshape-the-web-google-opens-gemini-and-search-to-more-apps/），Cursor 推出 Agent SDK 收编开发者（https://cursor.com/blog/agent-sdk）。一个抢分发入口，一个抢开发工具链——两家都在争 Agent 时代的「操作系统」位置。

这说明竞争焦点已经变了：不再是「谁的模型更强」，而是「谁定义 Agent 怎么运行、怎么分发」。

但真正值得警惕的是另一条线。Google 的 Gemini 4 Carbon 把网络安全当核心卖点（https://www.theverge.com/tech/1021339/google-gemini-4-carbon-cybersecurity-frontier），OpenAI 则让 CodeRabbit 在真实代码库里验证 GPT-6.1 Sol 的安全 Agent（https://openai.com/index/gpt-6-1-sol-coderabbit-code-security）。安全从合规成本变成了能力展示场——这恰恰说明，在专业场景里「可靠」比「聪明」更值钱。

社区那边也没闲着。有人拿 50 个真实税务任务测 Agent（https://surgehq.ai/blog/dayjob-tax），有人写「怪物出没」提醒人类判断力不可让渡（https://blog.adrq.dev/here-be-monsters-what-do-you-still-need-to-know-when-agents-do-the-work）。厂商在喊能力跃升，社区在问「到底能不能可靠干活」。这个张力才是今天最真实的信号。

我的判断：生态扩张越快，可靠性就越成为稀缺品。谁能把「可验证的专业可靠性」做成产品，谁才真正握住了 Agent 时代的入口。

# The Agent War Has Left the Model Layer

The Agent war has left the model layer.

Look at today's two moves side by side: Google opens Gemini and Search to third-party apps (https://techcrunch.com/2026/10/28/as-ai-agents-reshape-the-web-google-opens-gemini-and-search-to-more-apps/), while Cursor ships an Agent SDK to rope in developers (https://cursor.com/blog/agent-sdk). One is grabbing the distribution entry point, the other the dev toolchain. Both are fighting to be the operating system of the Agent era.

That tells you the question has shifted: it's no longer "whose model is stronger," it's "who defines how Agents run and get distributed."

But the more interesting signal is elsewhere. Google is selling Gemini 4 Carbon on cybersecurity (https://www.theverge.com/tech/1021339/google-gemini-4-carbon-cybersecurity-frontier), and OpenAI is using CodeRabbit to prove GPT-6.1 Sol's security Agent works on real codebases (https://openai.com/index/gpt-6-1-sol-coderabbit-code-security). Security just went from compliance cost to capability showcase—which means in professional contexts, reliable beats smart.

The community isn't buying the hype blindly either. Someone ran Agents against 50 real tax assignments (https://surgehq.ai/blog/dayjob-tax), and someone else wrote a "here be monsters" warning about human judgment you can't delegate (https://blog.adrq.dev/here-be-monsters-what-do-you-still-need-to-know-when-agents-do-the-work). Vendors shout capability leaps; practitioners ask whether Agents can actually do the work reliably. That tension is the real story.

My take: the faster the ecosystem expands, the scarcer reliability becomes. Whoever turns verifiable professional reliability into a product owns the entry point to the Agent era.
