# Agent 的胜负手不在模型，在入口

Agent 的胜负手不在模型，在入口。

今天两条新闻放一起看很说明问题：Google 把 Gemini 和搜索开放给第三方应用（https://techcrunch.com/2026/10/28/as-ai-agents-reshape-the-web-google-opens-gemini-and-search-to-more-apps/），Cursor 推出 Agent SDK 收编开发者（https://cursor.com/blog/agent-sdk）。一个抢分发，一个抢开发工具链，目标都是同一个位置——Agent 时代的『操作系统』。

这意味着竞争焦点变了。以前比谁的模型跑分高，现在比谁定义 Agent 怎么运行、怎么分发、怎么被调用。模型会趋同，入口不会。Google 有搜索和 Android 级别的分发网络，Cursor 有开发者的日常编辑器，这两样东西比多几个 benchmark 分数值钱得多。

另一边，OpenAI 走的是企业工作流路线：Retell 用语音 Agent 撑起每月 1 亿次通话（https://openai.com/index/retell-ai），ServiceNow 把模型嵌进企业核心流程（https://openai.com/index/openai-servicenow-partnership-expansion）。这是把 Agent 变成企业运营的毛细血管，收入模式从 API 调用变成深度嵌入。

但社区没买账。税务任务的基准评测（https://surgehq.ai/blog/dayjob-tax）和『怪物出没』式的反思（https://blog.adrq.dev/here-be-monsters-what-do-you-still-need-to-know-when-agents-do-the-work）在问同一个问题：Agent 到底能不能可靠干活？人类判断力能不能让渡？

我的判断：生态扩张越快，可靠性追问越紧迫。谁能在抢占入口的同时给出可验证的可靠性证据，谁才真正赢下这一局。光有入口没有信任，Agent 就是个更贵的聊天框。

# The Agent War Won't Be Won on Models—It'll Be Won on Entry Points

The agent war won't be won on models. It'll be won on entry points.

Look at today's two moves side by side. Google opens Gemini and Search to third-party apps (https://techcrunch.com/2026/10/28/as-ai-agents-reshape-the-web-google-opens-gemini-and-search-to-more-apps/). Cursor ships an Agent SDK to pull developers into its orbit (https://cursor.com/blog/agent-sdk). One grabs distribution, the other grabs the dev toolchain. Both are gunning for the same slot: the operating system of the agent era.

That's the real shift. It used to be about whose model scores higher. Now it's about who defines how agents run, how they get distributed, how they get called. Models converge. Entry points don't. Google has a search-and-Android-grade distribution network. Cursor has the editor developers live in. Those are worth more than a few benchmark points.

OpenAI is playing a different angle: embedding into enterprise workflows. Retell powers 100M monthly calls with voice agents (https://openai.com/index/retell-ai), and ServiceNow is wiring models into core enterprise processes (https://openai.com/index/openai-servicenow-partnership-expansion). That's turning agents into the capillaries of business operations—revenue shifts from API calls to deep embedding.

But the community isn't sold. A tax-task benchmark (https://surgehq.ai/blog/dayjob-tax) and a 'here be monsters' reality check (https://blog.adrq.dev/here-be-monsters-what-do-you-still-need-to-know-when-agents-do-the-work) are asking the same question: can agents actually do reliable work? Can we hand over human judgment?

My take: the faster the ecosystem expands, the more urgent the reliability question gets. Whoever grabs entry points and backs it with verifiable reliability evidence wins. Entry points without trust just make agents a more expensive chat box.
