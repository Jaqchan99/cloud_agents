# Agent 时代，浏览器是新的战场，而 Cloudflare 已经开火了

别再看那些花哨的 Agent 演示了，今天真正的信号是 Cloudflare 发布了 Kitesurf——一个为 AI Agent 从零打造的浏览器，直接在 V8 isolate 里跑。这不是一个工具更新，这是基础设施层的范式转移：Agent 不再需要凑合用人用的浏览器，它们要有自己的专用入口。

想想看，当 Agent 成为主流，谁控制浏览器谁就控制入口。Google 靠 Chrome 统治了人类上网，而 Cloudflare 正在赌 Agent 不会用 Chrome，它们需要更轻、更快、更隔离的架构。Kitesurf 就是冲着这个来的。

更有意思的是，同一天 Google Maps 开始加入 Agent 功能，能自动订餐订酒店。消费端 Agent 已经在落地，但它们跑在什么上面？还是旧的 Web 架构。Cloudflare 这一步，是在为下一代 Agent 应用铺路。

开发者社区还在纠结怎么从写代码到部署 Agent（HN 上热帖），而基础设施玩家已经开打了。别等到 Agent 成为日常再反应，那时候入口已经被瓜分完了。

# The Browser Is the New Battlefield for AI Agents, and Cloudflare Just Fired First

Stop staring at fancy agent demos. The real signal today is Cloudflare shipping Kitesurf — a browser built from scratch for AI agents, running directly in V8 isolates. This isn't a feature update; it's a paradigm shift at the infrastructure layer. Agents shouldn't have to make do with browsers designed for humans. They need their own dedicated entry point.

Think about it: when agents go mainstream, whoever controls the browser controls the gateway. Google ruled human web access with Chrome. Cloudflare is betting agents won't use Chrome — they need something lighter, faster, more isolated. Kitesurf is exactly that bet.

And here's the kicker: the same day, Google Maps rolls out agentic features that can order food and book hotels. Consumer agents are landing — but on what? The same old web stack. Cloudflare is building the runway for the next generation of agent-native apps.

Meanwhile, devs on HN are still asking how to go from writing code to deploying with agents. Infrastructure players are already fighting for the entry point. Don't wait until agents are everywhere to react — by then, the gates will be locked.
