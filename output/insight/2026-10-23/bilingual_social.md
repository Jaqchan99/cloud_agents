# Agent 的竞争已经不在模型层了，在「身份证」和「门禁卡」

Agent 的竞争已经不在模型层了，在「身份证」和「门禁卡」。

同一天里，NVIDIA 开源了给 Agent 集群用的隔离运行时 OpenShell，1Password 让 Agent 能替你登录但看不到密码，微软则把数据库评分改造成 RL 奖励来后训练 Agent。三件事指向同一个事实：Agent 要长期自主运行，缺的不是更聪明的模型，而是运行、身份、训练三块底座。

这解释了另一条新闻为什么重要——沃尔玛把 Agent 当新下单渠道接进来，亚马逊却在封堵。差别不在技术，在谁掌握用户意图的入口。Agent 一旦有了可信身份和稳定运行时，零售巨头就必须表态：你是渠道，还是劫持者？

所以别再盯着榜单了。真正的问题是：你的 Agent 拿的是谁的身份证，走的是谁的门禁。

# The agent race has moved past models — it's about IDs and door access now

The agent race isn't about models anymore. It's about IDs and door access.

In one day: NVIDIA open-sourced OpenShell, an isolated runtime for fleets of agents; 1Password shipped a way for agents to log in on your behalf without ever seeing your password; Microsoft turned database grading into RL rewards to post-train agents. Three different layers — runtime, identity, training — same conclusion: what agents lack isn't a smarter model, it's plumbing.

That's why the Walmart-vs-Amazon split matters. Walmart is rolling out the welcome mat for agents as a new checkout channel; Amazon is blocking them. The difference isn't tech, it's who owns the intent entry point. Once agents have trusted identities and stable runtimes, every retailer has to pick a side: channel or hijacker.

Stop watching leaderboards. Ask instead: whose ID is your agent carrying, and whose door is it walking through?
