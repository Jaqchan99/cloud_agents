# Agent 跑得比信任快，平台开始踩刹车

Agent 跑得比信任快，平台开始踩刹车。

Retell 的语音 Agent 月均 1 亿次通话，CodeRabbit 用 GPT-6.1 Sol 规模化做代码安全——Agent 的商业验证已经不需要再讨论了。但真正值得看的是另一面：The RealReal 开始用反机器人手段封堵购物 Agent，美银直接警告别把银行密码交给 AI 助理。

这不是技术故障，是制度在补课。Meta 力推 agentic 购物，把 Agent 自主权当卖点；The RealReal 眼里同一件事叫「滥用」。同一技术，两种叙事，说明 Agent 的合法身份根本没有共识。

更微妙的是 OpenAI 自己的高管说「不愿与别人的 Agent 开会」——入口争夺越激烈，互操作性越没人管。Oracle 应用入驻 ChatGPT、编程工具变成常驻助理 dots，都是在抢分发界面，而不是解决 Agent 之间怎么打交道。

工程侧的自下而上尝试已经出现：「规格优先」把契约思想引入 Agent 开发，试图用可验证的规格约束行为。但这只能补开发范式，补不了责任归属。

结论很直白：Agent 的能力兑现曲线很陡，制度补课曲线很平。两条线的 gap，就是接下来一年所有平台摩擦、银行免责和监管讨论的来源。谁先把这个 gap 当成产品问题而不是公关问题，谁才真正拿到规模化入场券。

# Agents Are Outrunning Trust, and Platforms Are Hitting the Brakes

Agents are outrunning trust, and platforms are hitting the brakes.

Retell is powering 100M monthly voice calls. CodeRabbit is scaling code security on GPT-6.1 Sol. The commercial validation debate is over. What matters now is the other side: The RealReal is deploying anti-bot measures against shopping agents, and Bank of America is telling customers not to hand their banking password to an AI assistant.

These aren't technical glitches. They're institutions catching up. Meta pushes agentic shopping as convenience; The RealReal sees the same behavior as abuse. Same tech, two narratives—there is no consensus on what a legitimate agent even is.

The tell: an OpenAI exec says he doesn't want to take meetings with someone else's agent. The more everyone fights over the entry point—Oracle apps inside ChatGPT, coding tools becoming the always-on assistant dots—the less anyone solves how agents talk to each other.

Bottom-up engineering is emerging: specification-first development brings contract thinking to agent behavior. Useful, but it fixes the dev paradigm, not liability.

The gap between the capability curve and the accountability curve is where all the platform friction, bank disclaimers, and regulatory noise will come from over the next year. Treat that gap as a product problem, not a PR problem, and you earn the right to scale.
