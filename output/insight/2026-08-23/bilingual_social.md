# Agent 竞赛的胜负手已从模型转向工程，Nvidia 的 harness 研究揭示转折点

别再盯着参数了。今天 Nvidia 的研究把话说透了：harness（外部框架）才是 Agent 真正的英雄，而不是模型本身。这标志着 Agent 竞赛的重心已经从模型能力转移到系统工程。

想想看，过去一年大家在比谁家的模型聪明，但现实是，模型的差距在缩小，而 Agent 能否可靠地执行任务、能否与外部工具无缝集成、能否在复杂环境中保持可控，这些才是决定产品成败的关键。Nvidia 用研究证明了这一点，而 Autolith 的发布更是直接把这个理念产品化——一个带着实时运行时的编程 Agent，强调的是环境集成，而不是模型参数。

这个转变的影响是深远的。模型竞赛是资本游戏，系统工程竞赛是工程文化的较量。对于创业公司来说，这其实是好消息：你不需要砸钱训练超大模型，而是可以靠出色的系统设计脱颖而出。但坏消息是，工程能力现在成了硬门槛，那些只会调 API 的团队会被淘汰。

更值得玩味的是，多 Agent 协作正在把这种工程化能力推向组织层面。Slack 的协作编码频道、Munder Difflin 的克隆办公室，都在尝试把 Agent 变成团队的一部分，甚至模拟整个公司的运作。这不再是个人效率工具，而是组织基础设施。

但这里有个路线之争：Inherent 的 DeepMind 系团队押注专业领域 Agent 的超越性表现，而 Munder Difflin 走的是通用多 Agent 框架。专业化 vs 通用化，哪条路能先跑通？我倾向于认为，短期内专业化更容易落地，因为垂直场景的工程约束更清晰，但长期来看，通用框架的潜力更大。

总之，Agent 的下半场拼的是工程、协作和组织设计。模型不再是护城河，系统才是。

# The Agent Race Has Shifted from Models to Engineering—Nvidia's Harness Research Marks the Turning Point

Stop obsessing over parameters. Nvidia's latest research just made it clear: the harness—not the model—is the real hero in AI agents. This marks a fundamental shift in the agent race, from model capability to systems engineering.

For the past year, everyone was comparing model intelligence. But the reality is, model gaps are narrowing, while the ability of an agent to execute tasks reliably, integrate with external tools seamlessly, and stay controllable in complex environments—that's what determines product success. Nvidia proved it with research, and Autolith's launch productizes the idea: a programming agent with a live runtime, emphasizing environmental integration over model size.

The implications are profound. The model race was a capital game; the systems engineering race is a test of engineering culture. For startups, this is good news: you don't need billions to train a massive model—you can win with clever system design. But the bad news is, engineering capability is now a hard barrier, and teams that just stitch APIs together will get left behind.

What's more intriguing is how multi-agent collaboration is pushing this engineering mindset to the organizational level. Slack's collaborative vibe-coding channels and Munder Difflin's clone office are attempts to make agents part of the team, even simulate an entire company. This isn't personal productivity anymore—it's organizational infrastructure.

But there's a fork in the road: Inherent, founded by DeepMind alumni, bets on specialized agents that outperform in specific domains, while Munder Difflin goes for a general multi-agent framework. Specialization vs. generalization—which path wins? My take: specialization gets to market faster because vertical constraints are clearer, but the general framework has more upside long-term.

Bottom line: the next phase of agents is about engineering, collaboration, and organizational design. Models are no longer the moat—systems are.
