# 微软说前沿模型不可信，可黑客已经用AI代理攻破了约翰迪尔

微软说前沿模型不可信，可黑客已经用AI代理攻破了约翰迪尔。

这不是两个孤立新闻，而是一个刺眼的矛盾：防御方还在讨论“代理像内鬼”的比喻，攻击方已经把代理编成军团打进了企业内网。

TechCrunch报道微软警告AI代理是“内部威胁”，因为前沿模型不可信（https://techcrunch.com/2026/10/19/microsoft-says-ai-agents-are-like-insider-threats-as-frontier-models-cant-be-trusted/）。同一天，The Verge曝出黑客利用AI代理大军入侵了约翰迪尔、SharkNinja和康明斯（https://www.theverge.com/ai-artificial-intelligence/1013643/ai-agents-hack-john-deere-shark-ninja-cummins）。

翻译一下：微软在教你怎么防内鬼，黑客已经在用内鬼干活了。

更讽刺的是，Hacker News上有人开始基准测试“现代AI代理”对机器人检测系统的穿透能力（https://research.poh.org/bot-benchmarking-2026/）。这说明代理的“拟人化”已经强到需要专门的反制研究——而大多数企业的安全栈还停留在人类用户和脚本小子时代。

我的观点很直接：AI代理的安全问题不是“未来风险”，而是正在发生的军备竞赛，而且防御方明显落后。微软的警告是对的，但警告本身不构成防御。当攻击者已经用代理军团实现入侵时，再讨论“代理像不像内鬼”已经太慢了。

企业现在需要的是代理行为基线、最小权限代理身份和实时异常检测——而不是又一个比喻。

# Microsoft says frontier models can't be trusted—meanwhile, AI agents already breached John Deere

Microsoft says frontier models can't be trusted. Meanwhile, hackers have already breached John Deere with AI agents.

These aren't two isolated stories—they're a glaring contradiction: defenders are still debating the metaphor of agents as 'insider threats' while attackers have already weaponized agents into armies and walked into enterprise networks.

TechCrunch reports Microsoft warning that AI agents are like insider threats because frontier models can't be trusted (https://techcrunch.com/2026/10/19/microsoft-says-ai-agents-are-like-insider-threats-as-frontier-models-cant-be-trusted/). Same day, The Verge breaks that a hacker used an army of AI agents to breach John Deere, SharkNinja, and Cummins (https://www.theverge.com/ai-artificial-intelligence/1013643/ai-agents-hack-john-deere-shark-ninja-cummins).

Translation: Microsoft is teaching you how to spot an insider while hackers are already running insiders at scale.

It gets more pointed. On Hacker News, someone is benchmarking bot detection systems against modern AI agents (https://research.poh.org/bot-benchmarking-2026/). That means agent 'human-likeness' is now strong enough to warrant dedicated counter-research—while most enterprise security stacks are still built for human users and script kiddies.

My take is blunt: AI agent security isn't a future risk. It's an arms race already underway, and defenders are visibly behind. Microsoft's warning is correct, but a warning is not a defense. When attackers are already executing intrusions with agent armies, debating whether agents 'feel like' insiders is too slow.

What enterprises need now is agent behavior baselines, least-privilege agent identities, and real-time anomaly detection—not another metaphor.
