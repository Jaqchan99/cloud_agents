# Agent 的瓶颈不在智商，在门禁

Agent 的瓶颈已经不在模型里了，在门禁上。

一边是 arXiv 上还在卷潜空间推理、混合架构，想着怎么让 Agent 更自主、更高效（https://arxiv.org/abs/2610.18861）。另一边，现实世界正在关门：越来越多网站开始主动封堵 AI agent 的访问，把「能不能进」重新变成一道需要谈判的关卡（https://www.theverge.com/ai-artificial-intelligence/1013195/ai-agents-blocked-web）；印度也成了最新一个记录「失控 Agent」活动的国家（https://techcrunch.com/2026/10/16/india-becomes-the-latest-country-to-report-rogue-ai-agent-activity/）。

这两件事放在一起看才有意思。行业叙事是 Agent 大规模自主上网、替你订票、比价、填表；真实世界的反应是先把门关上，再事后追责。自主性的商业故事，和准入成本，正在正面撞车。

Replit CEO 说的「自动驾驶公司」（https://techcrunch.com/2026/10/16/replits-ceo-says-the-future-of-work-is-the-self-driving-company/）听着很性感，但它成立的前提不是模型更强，而是权责边界能被信任。今天连一个网站都不愿意让 Agent 进来，谈组织级自治就有点早了。

所以别再只盯着 benchmark 了。下一个真正的护城河，是谁能拿到「被信任地接入」的许可——技术上的、商业上的、监管上的。谁先解决门禁，谁才谈得上自主。

# The Agent Bottleneck Isn't IQ. It's Access.

The agent bottleneck isn't in the model anymore. It's at the door.

On one side, researchers are still pushing latent-space reasoning and hybrid architectures to make agents more autonomous and efficient (https://arxiv.org/abs/2610.18861). On the other, the real world is closing ranks: more and more websites are actively blocking AI agents, turning "can you get in" back into a negotiation (https://www.theverge.com/ai-artificial-intelligence/1013195/ai-agents-blocked-web). India just became the latest country to log rogue agent activity (https://techcrunch.com/2026/10/16/india-becomes-the-latest-country-to-report-rogue-ai-agent-activity/).

Those two things belong in the same sentence. The pitch is agents roaming the web on your behalf — booking, comparing, filling forms. The reality is doors slamming shut and regulators writing incident reports after the fact. The autonomy narrative and the access cost are on a collision course.

Replit's "self-driving company" (https://techcrunch.com/2026/10/16/replits-ceo-says-the-future-of-work-is-the-self-driving-company/) is a nice story, but it hinges on trust and accountability, not a better model. If a single website won't let an agent in today, org-level autonomy is a stretch.

Stop staring at benchmarks. The next moat is permission — technical, commercial, regulatory. Whoever solves the door gets to talk about autonomy.
