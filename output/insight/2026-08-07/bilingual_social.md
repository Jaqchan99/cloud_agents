# Agent 越强，人类越瞎：安全监督正在成为最大瓶颈

今天最值得聊的不是哪家模型又登顶了，而是一个被大多数人忽略的隐患：Agent 越强，人类越难管住它。

看三件事。Qwen3.8 Max 在 Agentic Index 上登顶，Meta 推出面向大型代码库的编程 Agent Muse Code，Prime Agent 甚至开始探索自我改进的强化学习路径。能力竞赛已经白热化，模型厂商都在把 Agent 能力当作差异化核心。

但另一边，ScaleX 的研究给了一记警钟：在 4 万次游戏运行中，人类审批 AI Agent 命令时漏掉了 1/3 的威胁。也就是说，当 Agent 越来越自主，人类监督却越来越不可靠。这不是小概率事件，是结构性缺陷。

更讽刺的是，Google Maps 已经开始把 Agent 塞进普通人的日常——点餐、订酒店，这些真实世界的任务交给 Agent 执行。消费级应用的大门打开了，但普通用户面对 Agent 时的安全风险比开发者更高，因为他们既没有技术背景，也没有耐心去审查每一步操作。

所以我的观点很明确：Agent 的下一个瓶颈不是模型能力，而是安全监督。如果人类连 1/3 的威胁都发现不了，那 Agent 越强，风险越大。行业该把资源从堆参数转向堆可靠性了。

# Smarter Agents, Blinder Humans: Oversight Is the Real Bottleneck

Everyone's talking about which model topped the Agentic Index today. But the real story is the one nobody wants to face: the more capable agents get, the worse we are at supervising them.

Consider this. Qwen3.8 Max just ranked #1 on the Agentic Index. Meta shipped Muse Code, an agent built for massive codebases. Prime Agent is exploring self-improving RL. The capability race is white-hot — every lab is positioning agent skills as the new battleground.

But here's the kicker. A ScaleX study found that humans missed 1 in 3 threats when approving agent commands across 40,000 game runs. One in three. That's not a rounding error; that's a structural flaw in how we oversee autonomous systems.

And just as this lands, Google Maps is putting agents into everyday life — ordering food, booking hotels. Consumer agents are here, and they're being used by people who have neither the technical chops nor the patience to audit every action. The risk profile just got steeper.

My take: the next bottleneck for agents isn't intelligence — it's oversight. If we can't catch a third of dangerous actions in a controlled study, every point of capability gain multiplies real-world risk. It's time to shift investment from raw capability to reliable control.
